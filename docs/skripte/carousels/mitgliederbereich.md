# Der Mitgliederbereich — Carousel-Skripte

Sechs Carousels rund um den geschützten Mitgliederbereich. Kurze Texte, ruhiger Ton, du-Form.
Ziel jeder Serie: zeigen, was drinnen wartet – und zum Einstieg (Bewusstseinstest / Mitglied werden) einladen.

Slide-Prinzip: Slide 1 ist das Hook-Cover. Die mittleren Slides tragen den Nutzen in Schritten.
Die letzte Slide bringt einen Merksatz und den Handlungsaufruf. Jede Serie hat eine fertige Caption.
