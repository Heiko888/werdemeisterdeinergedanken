# Marketing-Carousels · Werde Meister deiner Gedanken

Post-Captions für die gebrandeten Funnel-Carousels aus `docs/carousels/marketing-serien.mjs`.
Die Slides selbst werden dort im Code gebaut; hier stehen die dazugehörigen
**Captions** (Post-Texte für Instagram/LinkedIn) – Hook, kurzer Sog, klarer
Call-to-Action und Hashtags. Ton: ruhig, klar, ermächtigend, in der Du-Form.
Der `key` verweist jeweils auf die Serie in `marketing-serien.mjs`.
