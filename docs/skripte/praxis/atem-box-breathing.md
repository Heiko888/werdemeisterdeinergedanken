# Praxis – Box Breathing (Atemübung)

**Format:** Wort-für-Wort zum Einsprechen · **Länge:** 3–5 Min · **Stufe 6**
`[Regie] Ruhig, klar, fast getaktet. Beim Zählen echtes 4-Sek-Tempo vorgeben.`

---

Box Breathing wird sogar in Hochdruck-Berufen genutzt – … von Menschen, die unter größtem Stress klar bleiben müssen. … Vier gleich lange Phasen bilden ein Quadrat aus Atem: … einatmen, … halten, … ausatmen, … halten. … Ruhig und klar. …

Setz dich aufrecht hin. … Beide Füße auf dem Boden. … Der Rücken gerade, aber nicht steif. … Wenn du magst, schließe die Augen. …

Wir atmen in vier Phasen zu je vier Sekunden. … Falls vier Sekunden sich zu lang anfühlen, … nimm einfach drei. … Der gleichmäßige Rhythmus ist wichtiger als die Länge. …

Wir beginnen. …

Einatmen … zwei … drei … vier. … Halten … zwei … drei … vier. … Ausatmen … zwei … drei … vier. … Halten … zwei … drei … vier. …

Und weiter. … Ein … zwei … drei … vier. … Halten … zwei … drei … vier. … Aus … zwei … drei … vier. … Halten … zwei … drei … vier. […Pause: 3 Sek]

Noch eine Runde mit mir. … Ein … zwei … drei … vier. … Halten … zwei … drei … vier. … Aus … zwei … drei … vier. … Halten … zwei … drei … vier. […Pause: 3 Sek]

*Ganz gleichmäßig. Wie ein Quadrat, das du mit dem Atem nachzeichnest.* …

Führe jetzt noch zwei bis drei Runden in deinem eigenen Tempo weiter. … Ein – halten – aus – halten. … Ich bin still. […Pause: 25 Sek]

Und dann lass den Rhythmus los. … Kehr zurück zu deinem natürlichen Atem. …

Spür die Zentriertheit, die entstanden ist. … Ruhig und wach zugleich. …

Genau diesen Zustand kannst du dir vor herausfordernden Momenten holen – … wenn du Fokus und Gelassenheit gleichzeitig brauchst.
