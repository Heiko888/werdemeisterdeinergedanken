# Praxis – 4-6-Atmung (Atemübung)

**Format:** Wort-für-Wort zum Einsprechen · **Länge:** ~3 Min · **Stufe 4**
`[Regie] Klar und ruhig. Tempo beim Zählen real vorgeben.`

---

Diese Atmung gibt dir in wenigen Minuten Halt. … Ein fester Rhythmus, an dem du dich festhalten kannst: … einatmen auf vier, … ausatmen auf sechs. … Ganz einfach. …

Setz dich bequem hin oder bleib stehen – … diese Übung funktioniert überall, … und niemand merkt, dass du sie gerade machst. …

Wenn du magst, schließe die Augen. … Sonst senk einfach den Blick. …

Wir beginnen. … Atme durch die Nase ein und zähl mit mir. …

Ein … zwei … drei … vier. … Und aus … zwei … drei … vier … fünf … sechs. …

Halte keine Luft an – … der Übergang bleibt weich. …

Noch einmal. … Ein … zwei … drei … vier. … Aus … zwei … drei … vier … fünf … sechs. …

Und weiter. … Ein … zwei … drei … vier. … Aus … zwei … drei … vier … fünf … sechs. […Pause: 4 Sek]

*Ruhig weiter in diesem Rhythmus.* … Ein … zwei … drei … vier. … Aus … zwei … drei … vier … fünf … sechs. […Pause: 4 Sek]

Atme so noch ein paar Runden allein weiter. … Vier ein, … sechs aus. … Ich bin kurz still. […Pause: 20 Sek]

Und jetzt lass das Zählen los. … Kehr zurück zu deinem natürlichen Atem. …

Und bemerke den Unterschied. … Wahrscheinlich ist etwas ruhiger geworden. … Etwas klarer. …

Diesen Rhythmus kannst du jederzeit abrufen – … vor einem Gespräch, … in einem Wartemoment, … immer dann, wenn du schnell wieder bei dir ankommen willst.
