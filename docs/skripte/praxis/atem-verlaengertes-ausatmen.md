# Praxis – Verlängertes Ausatmen (Atemübung)

**Format:** Wort-für-Wort zum Einsprechen · **Länge:** 3–5 Min · **Stufe 4**
`[Regie] Ruhig. Beim Zählen das Tempo real vorgeben, damit man mitatmen kann.`

---

Diese Übung ist ein einfacher Hebel mit großer Wirkung. … Wenn dein Ausatmen länger ist als dein Einatmen, … schaltet dein Körper von selbst auf Beruhigung. … Du musst nichts glauben – du wirst es gleich spüren. …

Setz oder leg dich bequem hin. … Wenn es für dich angenehm ist, schließe die Augen. … Und lass die Schultern einmal locker fallen. …

Wir atmen durch die Nase ein und zählen bis vier, … und atmen dann ruhig aus und zählen bis sechs. … Kein Pressen. … Das Ausatmen soll länger sein, aber völlig entspannt. …

Wir beginnen. …

Einatmen … zwei … drei … vier. … Und ausatmen … zwei … drei … vier … fünf … sechs. …

Noch einmal. … Ein … zwei … drei … vier. … Aus … zwei … drei … vier … fünf … sechs. …

*Und weiter in deinem Rhythmus.* … Ein … zwei … drei … vier. … Aus … zwei … drei … vier … fünf … sechs. […Pause: 5 Sek]

Wenn es sich gut anfühlt, … kannst du das Ausatmen noch etwas verlängern – bis acht. … Aber nur, wenn es mühelos bleibt. […Pause: 8 Sek]

Spür, wie dein Körper mit jedem längeren Ausatmen ein kleines Stück mehr loslässt. … Die Schultern … der Kiefer … der Bauch. […Pause: 10 Sek]

Atme so weiter, in deinem eigenen Tempo, … für ein paar Atemzüge. … Ich bin jetzt still. […Pause: 20 Sek]

Und dann lass das Zählen los. … Kehr zurück zu deinem ganz natürlichen Atem … und spür den Unterschied zu vorhin. …

Merk dir: … Nicht die Menge Luft zählt, … sondern das Verhältnis. … Ausatmen länger als Einatmen. … Diesen Hebel hast du immer dabei.
