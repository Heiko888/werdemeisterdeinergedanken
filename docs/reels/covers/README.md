# Reel-Cover – 16 fertige Vorlagen

Alle 16 Cover der Serie „Mentale Selbstverteidigung" – Headline, Akzentwort,
Nummer und Logo sind schon eingesetzt. Marken-Schrift (Fraunces/Inter) und
leaf→teal-Verlauf wie auf der Website.

## So machst du daraus Bilder
1. Leg dein Hintergrundbild (Nano-Banana-Vorlage) als **`vorlage.png`** in
   diesen Ordner (neben die HTML-Dateien).
2. Öffne `cover-01.html` … `cover-16.html` im Browser.
3. Screenshot im Format **1080×1920** (9:16) – fertig ist das Cover.
   (Tipp: Browserfenster auf 1080 px Breite, oder DevTools-Geräteansicht
   1080×1920, dann Vollbild-Screenshot der `.cover`-Fläche.)

## Dateien
- `cover-01.html` … `cover-16.html` – die 16 Cover
- `_fonts.css` – eingebettete Marken-Schriften (nicht umbenennen)
- `_cover.css` – Layout/Farben (nicht umbenennen)
- `logo.png` – freigestelltes Neon-Gehirn
- `vorlage.png` – **legst du selbst dazu** (dein Hintergrund)

## Text ändern?
Öffne die jeweilige `cover-NN.html` und ändere `.tag`, `.headline` oder das
`<span class="accent">…</span>`. Bei langer Headline `class="headline small"`.
