# Logo-Paket (Gold · Schriftlogo · Creme)

Fertige Dateien zum Weitergeben (Grafiker, Druckerei, Canva, Social Media).
Erzeugt mit `npm run logo-paket` (`tools/print/logo-paket.mjs`).

| Datei | Inhalt | Format |
|---|---|---|
| `WMDG-Emblem-Gold.png` | Gehirn-Emblem in Gold, freigestellt | 2000 × 2000, transparent |
| `WMDG-Schriftlogo-auf-Hell.png` | Schriftlogo „WERDE MEISTER / DEINER GEDANKEN" für helle Flächen (Tinte + Gold) | transparent |
| `WMDG-Schriftlogo-auf-Dunkel.png` | Schriftlogo für dunkle Flächen (Creme + helles Gold) | transparent |
| `WMDG-Logo-komplett-auf-Hell.png` | Emblem + Schriftlogo für helle Flächen | transparent |
| `WMDG-Logo-komplett-auf-Dunkel.png` | Emblem + Schriftlogo für dunkle Flächen | transparent |
| `WMDG-Creme-Hintergrund-{1x1,4x5,9x16,16x9}.png` | Creme-Hintergrund pur | 1080² / 1080×1350 / 1080×1920 / 1920×1080 |
| `WMDG-Creme-Hintergrund-Aura-{…}.png` | Creme mit warmer Gold-Aura (wie Website) | wie oben |
| `WMDG-Logo-auf-Creme-16x9.png` | Vorschau: Komplett-Logo auf Creme | 1920 × 1080 |

## Farbwerte

| Farbe | Hex | RGB | Verwendung |
|---|---|---|---|
| Creme (Papier) | `#F6F4EE` | 246 / 244 / 238 | Haupt-Hintergrund der Website |
| Creme tiefer | `#EFECE2` | 239 / 236 / 226 | Wechsel-Sektionen |
| Gold 500 | `#D9A93A` | 217 / 169 / 58 | Gold-Akzent, Verlaufsstart |
| Gold 700 | `#7E6410` | 126 / 100 / 16 | Verlaufsende / Gold-Text auf Hell |
| Gold 300 | `#F2D489` | 242 / 212 / 137 | Gold auf Dunkel |
| Tinte | `#16231F` | 22 / 35 / 31 | Schrift auf Hell |

Schrift der Wortmarke: **Fraunces** Regular (400), Versalien, Sperrung 0,1 em
(Zeile 1) bzw. 0,24 em (Zeile 2) – identisch mit dem Website-Header
(`src/components/visuals/Logo.tsx`).
